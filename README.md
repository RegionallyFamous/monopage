# Monopage

![Riso-style illustration of a continuous Monopage campaign page with modular blocks and anchor navigation](docs/assets/monopage-riso-hero.jpg)

Monopage is AI-native one-page WordPress.

It keeps the parts that make WordPress powerful: the Site Editor, blocks, media, themes, real hosting, users, and WP-CLI. Then it clears away the sprawl that gets in the way of a focused launch page.

One page. One story. One obvious next move.

## Why It Exists

Most AI-made sites begin as a single page: a launch, offer, waitlist, event, portfolio, product teaser, campaign, or strange little idea that deserves a real URL.

WordPress can power that beautifully. But the normal WordPress experience asks people to think about posts, pages, archives, dashboards, menus, settings, and structure before the idea is even alive.

Monopage turns WordPress into a campaign canvas. Edit the homepage in the Site Editor. Move visitors through same-page sections. Ask Codex to reshape the copy, tune the design, or deploy the site. Keep everything else out of the way.

## What It Includes

- A focused WordPress plugin for one-page sites.
- Monopage Canvas, a bold block theme with a polished starter homepage.
- A direct editing flow that opens to the homepage canvas.
- Same-page navigation built around anchors, not page-hopping.
- Focus Mode that keeps the authoring surface calm.
- A Codex skill that understands Monopage sites and can package, deploy, and validate them.
- A WordPress Playground demo so the whole idea can be tried before installing anything.

## Built For AI

Monopage is made for people who use AI to make real things.

Ask Codex to rewrite the offer, add proof, change the vibe, build a pricing section, sharpen the mobile layout, or deploy to a WordPress host. The companion skill keeps the work inside the Monopage model: one editable page, anchor navigation, real WordPress, clean Focus Mode, and no random admin clutter.
