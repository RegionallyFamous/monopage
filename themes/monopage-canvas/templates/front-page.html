FAQ

Questions before the lights go up?

Where do I edit the visible homepage?

Edit the Site Editor front-page template. The Home page exists as the WordPress routing page, but the visible homepage comes from the template.

Can I add new sections?

Yes. Add a block group, give it a stable anchor, and link to it with a same-page href such as #start or #services.

Can I still use the rest of WordPress?

Yes. Focus Mode narrows the interface, but WordPress core, Media, plugins, users, and capabilities remain intact.

Why does every link stay on this page?

Monopage is designed around a single-page site. The starter keeps navigation focused on page sections instead of sending visitors to other routes.
